# Componente de grafos
Nodos: estudiantes en riesgo (≥ 3 alertas), programas y estratos. Aristas: estudiante–programa y estudiante–estrato.
- Ejecutar: `python graph/grafo_desercion.py` → `grafo_riesgo.png` y `grafo_riesgo.graphml` (abrible en Gephi/Neo4j).
- El grado de cada nodo programa/estrato indica dónde se concentra el riesgo.
